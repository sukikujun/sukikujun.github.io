##  {{ page.title }}

1. Docker を install する
2. `docker pull container-registry.oracle.com/database/free:latest` で Image を取得
3. コンテナーを立てる
```
docker run -d --name oracle-free \
  -p 1521:1521 \
  -e ORACLE_PWD=admin \
  -v oracle_data:/opt/oracle/oradata \
  container-registry.oracle.com/database/free:latest
```
4. VS Code [Oracle SQL Developer Extension for VSCode](https://marketplace.visualstudio.com/items?itemName=Oracle.sql-developer) 拡張機能をインストール
5. 接続を追加
```
Username: SYSTEM
Password: admin
Hostname: localhost
Port: 1512
Service Name: FREEPDB1
```
