## Oracle19 構築

> [Oracle19 db_home](https://www.oracle.com/database/technologies/oracle19c-linux-downloads.html) をダウンロード

```bash
# 1. docker-images をクローン
$ git clone https://github.com/oracle/docker-images.git

# 2. oracle19 db_home を dockerfiles/19.3.0 に移動
$ mv ~/LINUX.X64_193000_db_home.zip ~/docker-images/OracleDatabase/SingleInstance/dockerfiles/19.3.0

# 3. build oracle19 docker image
$ ./buildContainerImage.sh -v 19.3.0 -e
```

> Oracle19 インスタンスを起動

`docker-compose.yml` を作成

```yml
services:
  oracle19c:
    image: oracle/database:19.3.0-ee
    container_name: oracle19c
    ports:
      - "1521:1521"
      - "5500:5500"
    environment:
      ORACLE_PWD: admin
    volumes:
      - oracle-data:/opt/oracle/oradata
    restart: unless-stopped

volumes:
  oracle-data:
```

`docker compose up -d` で起動

> `sqlplus / as sysdba` でログインできない場合

```bash
echo 'export ORACLE_SID=ORCLCDB' >> ~/.bashrc
source ~/.bashrc
```

1. Docker を install する
2. `docker pull container-registry.oracle.com/database/free:latest` で Image を取得
3. コンテナーを立てる

```
docker run -d --name oracle-free \
  -p 1521:1521 \
  -e ORACLE_PWD=admin \
  -v oracle_data:/opt/oracle/oradata \
  container-registry.oracle.com/database/free:latest
```

1. VS Code [Oracle SQL Developer Extension for VSCode](https://marketplace.visualstudio.com/items?itemName=Oracle.sql-developer) 拡張機能をインストール
2. 接続を追加

```
Username: SYSTEM
Password: admin
Hostname: localhost
Port: 1512
Service Name: FREEPDB1
```
