## [Neovim](https://neovim.io/)

> [インストール手順](https://neovim.io/doc/install/)

### Windows

1. Windows でインストール手順

```shell
$ winget install Neovim.Neovim
```

### Mac

1. Mac でインストール手順

```bash
$ brew install neovim
```

2. Mac でバージョンアップ手順

```bash
$ brew update
$ brew upgrade neovim
```

3. Mac [nvim-macos-x86_64.tar.gz](https://github.com/neovim/neovim/releases/latest/download/nvim-macos-x86_64.tar.gz) でインストール

`export PATH="/usr/local/neovim/bin:$PATH"` を `.zshrc` に追加し、`source ~/.zshrc` で更新

```bash
$ tar xzf nvim-macos-x86_64.tar.gz 
$ mv nvim-macos-x86_64 /usr/local/neovim
$ cd /usr/local/neovim/bin
bin $ ./nvim ~/.zshrc
```
