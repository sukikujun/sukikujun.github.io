## Mac

1. rnenv でインストール

```bash
brew install rbenv
rbenv install 3.4.9
rbenv global 3.4.9
```

> MacOS インストール後まだ古いバージョン

原因：パスが System のまま、rbenv でインストールしたのではない
解決策：rbenv 初期化を .zshrc に入れる

```bash
echo 'eval "$(rbenv init - zsh)"' >> ~/.zshrc
```
